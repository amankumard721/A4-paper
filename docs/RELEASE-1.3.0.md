# A4 Paper Typing 1.3.0

Version code: 6. Package: com.a4sizepaper.typing.texttopdf.

- Full-page writing area with pinch zoom and improved keyboard focus recovery.
- Font color sheet with selection-aware controls.
- Review mode with return-to-edit, Save PDF and Share PDF actions.
- Compact Table and Image tabs with contextual controls and configurable table dimensions.
- Image corner resizing with preserved proportions, width presets and alignment.
- Touch-friendly column resizing with persistent widths, merged-cell support and Undo/Redo.
- Updated launcher artwork.

Release artifacts use the existing local upload key. The debug APK is for updating previous debug installations. Signing material and generated binaries are excluded from Git.

Physical-device validation remains necessary for Android keyboard behavior, pinch zoom, native sheets and save/share flows.
